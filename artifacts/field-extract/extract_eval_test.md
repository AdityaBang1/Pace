An emitted value on a field the document never states is a false positive, which is the failure section-span gold cannot see. ## Reliability: confidence against measured precision

| Confidence band | Values | Correct | Precision | 95% lower bound |
|---|---:|---:|---:|---:|
| 0.00-0.70 | 0 | 0 | - | - |
| 0.70-0.90 | 21 | 21 | 1.000 | 0.867 |
| 0.90-0.99 | 45 | 42 | 0.933 | 0.837 |
| 0.99-1.00 | 0 | 0 | - | - |

Read the bands in order — 0.70-0.90: 21/21 = 1.000, 0.90-0.99: 42/45 = 0.933. The table is **not monotone**: 0.90-0.99 (42/45 = 0.933) sits below 0.70-0.90 (21/21 = 1.000). Those bands hold enough values that the reversal is not only small-sample noise. The errors the higher band keeps are `office_hours` at 0.95 x2, `grading` at 0.90, so the remaining reversal comes from values the higher confidence cannot separate from the correct ones.
